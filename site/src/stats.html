≈ includes an estimate. An encrypted bus hides what each record is, and nothing is decrypted to count it. A message is counted from an encrypted record’s size: that misses about 2% of them, short ones with no body, and can take a session’s start on a long branch for one. A session is counted from the repo’s name registry, which isn’t encrypted, and which also names sessions that other sessions started.
